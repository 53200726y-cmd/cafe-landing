# cafe-landing

가상의 카페 "Morning Brew"를 위한 간단한 정적 랜딩 페이지입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 우리 이야기, 오시는 길, 푸터) |
| `style.css` | 스타일시트 (반응형 레이아웃, 카페 톤의 갈색 색상) |

## 실행 방법

빌드 과정 없이 `index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

```sh
open index.html
```

## 참고

- 상호, 메뉴, 가격, 주소는 모두 예시 내용이므로 실제 정보로 바꿔서 사용하세요.
- 외부 라이브러리나 의존성이 없습니다.
